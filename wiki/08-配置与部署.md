# 配置与部署

## 环境要求

| 依赖 | 版本要求 | 说明 |
|------|----------|------|
| JDK | 17+ | 编译运行后端 |
| Maven | 3.6+ | 构建后端 |
| Node.js | 18+ | 运行前端 |
| MySQL | 8.0+ | 数据持久化 |
| Redis | 6.0+ | 缓存 |
| Nacos | 2.2+ | 服务注册与发现（standalone 模式） |

## 启动顺序

```
1. MySQL          ← 创建数据库和表
2. Redis          ← 启动缓存服务
3. Nacos          ← 启动注册中心
4. Gateway        ← 启动网关服务
5. User Service   ← 启动用户服务
6. API Service    ← 启动短信服务（含 CMPP 连接）
7. Frontend       ← 启动前端开发服务器
```

## 1. 数据库初始化

```bash
mysql -u root -p < backend/user-service/src/main/resources/db/init.sql
```

创建 `ink_sms_gateway` 数据库 + `users` 表 + 2 条测试数据。

## 2. 启动 Redis

```bash
# Windows
redis-server

# 默认配置
# host: localhost
# port: 6379
```

## 3. 启动 Nacos

```bash
cd <nacos-home>/bin
startup.cmd -m standalone
```

**Nacos 端口**：HTTP `8848`，gRPC `9848`（8848 + 1000）

> **重要**：Nacos 3.x 需添加 JVM 参数以兼容 Spring Cloud Alibaba 2023.x：
> ```bash
> set JAVA_OPT="%JAVA_OPT% -Dnacos.server.grpc.port.offset=1000"
> startup.cmd -m standalone
> ```

## 4. 启动后端服务

### 编译公共模块

```bash
cd backend
mvn clean install -pl common
```

> `common` 被 `gateway` 和 `user-service` 依赖，修改后必须先 `mvn install`。

### 启动网关服务

```bash
cd gateway
mvn spring-boot:run
```

端口：`8080`

### 启动用户服务

```bash
cd ../user-service
mvn spring-boot:run
```

端口：`8081`

### 启动 API 服务

```bash
cd ../api
mvn spring-boot:run
```

端口：`8082`（HTTP）、`7891`（CMPP 下游）、`7890`（CMPP 上游连接）

> API 服务启动后会自动连接 CMPP 上游服务器（emay），进行 Connect 认证并开始心跳维持。

## 5. 启动前端

```bash
cd front
npm install
npm run dev
```

端口：`3000`，API 请求代理到 `http://localhost:8080`

## 配置详解

### 网关服务 — application.yml

**文件**：`gateway/src/main/resources/application.yml`

```yaml
server:
  port: 8080

spring:
  application:
    name: gateway-service

  cloud:
    nacos:
      discovery:
        server-addr: localhost:8848      # Nacos 地址
        namespace: public
        group: DEFAULT_GROUP
      config:
        enabled: false                   # 不使用 Nacos 配置中心
        import-check:
          enabled: false

    gateway:
      discovery:
        locator:
          enabled: true                  # 开启服务发现自动路由
          lower-case-service-id: true
      routes:
        - id: user-service
          uri: lb://user-service         # 负载均衡到用户服务
          predicates:
            - Path=/api/user/**          # 路由匹配规则
        - id: api-service
          uri: lb://api-service          # 负载均衡到 API 服务
          predicates:
            - Path=/api/sms/**           # 短信 API 路由

    data:
      redis:
        host: localhost
        port: 6379
        database: 0                      # 网关使用 DB 0
        timeout: 3000ms
        lettuce:
          pool:
            max-active: 8
            max-idle: 8
            min-idle: 0
            max-wait: -1ms

logging:
  level:
    com.ink.gateway: DEBUG
    org.springframework.cloud.gateway: DEBUG
    reactor.netty.http.server: DEBUG
```

### API 服务 — application.yml

**文件**：`api/src/main/resources/application.yml`

```yaml
server:
  port: 8082

spring:
  application:
    name: api-service
  cloud:
    nacos:
      discovery:
        server-addr: localhost:8848
        namespace: public
        group: DEFAULT_GROUP
      config:
        enabled: false
        import-check:
          enabled: false

# CMPP 下游服务器配置（接受 SP 连接）
cmpp:
  server:
    port: 7891                           # 下游 CMPP 服务器端口
    allowed-sp-list: "test:123456"       # SP 认证列表
    boss-threads: 1
    worker-threads: 4
  # CMPP 上游连接配置（连接到 CMPP 服务器）
  upstream:
    host: 127.0.0.1
    port: 7890                           # emay 虚拟短信网关端口
    sp-id: test
    shared-secret: "123456"
    version: 0x20
    heartbeat-interval: 60               # 心跳间隔（秒）
    reconnect-interval: 10               # 重连间隔（秒）
    max-reconnect-interval: 60           # 最大重连间隔（秒）

logging:
  charset:
    console: UTF-8
    file: UTF-8
  level:
    com.ink: DEBUG
    io.netty: DEBUG
```

## 已知事项与注意事项

### Nacos

- 必须以 **standalone 模式**启动（`startup.cmd -m standalone`）
- Nacos 3.x 与 Spring Cloud Alibaba 2023.x 存在 gRPC 端口偏移兼容问题，需设置 JVM 参数 `-Dnacos.server.grpc.port.offset=1000`
- Nacos 实际 HTTP 端口为 `8848`，gRPC 端口为 `9848`（8848 + 1000）
- Nacos `token.secret.key` 必须 ≥ 32 字节且 Base64 编码

### 网关

- 网关基于 **WebFlux**，不可引入 `spring-boot-starter-web` 或任何 Servlet 依赖
- Knife4j 配置在 WebFlux 环境下不生效
- JWT 密钥（`jwt.secret`）长度必须 ≥ 256 bit（32 字节），否则 HS512 签名报错

### 数据库

- `users` 表中 `username`、`email`、`phone` 有 UNIQUE 约束
- 索引 `idx_username`/`idx_email`/`idx_phone` 与 UNIQUE 约束产生的索引冗余
- `last_login_ip` 使用 `VARCHAR(45)` 兼容 IPv6 地址

### 公共模块

- `common` 模块修改后必须先 `mvn install`，否则其他模块引用的是旧 JAR
- Lombok 版本 1.18.40 支持 JDK 25

### CMPP / API 服务

- API 服务启动后会同时启动 CMPP 下游服务器（:7891）和连接上游 CMPP 服务器（:7890）
- CMPP 上游连接支持自动心跳和断线重连
- Deliver 消息解析已适配 emay 虚拟短信网关格式（无 Msg_Src/Fee 字段，Src_Terminal_Id 为 21 字节固定格式）
- 压力测试表明 API 吞吐量可达 3,600+ msg/sec（20 并发）
