# 公共模块详解

## 概述

`common` 模块是一个纯 JAR 包，不独立运行，被 `gateway` 和 `user-service` 共同依赖。提供工具类、常量定义、统一响应体和全局异常处理。

## 目录结构

```
common/src/main/java/com/ink/common/
├── config/
│   └── RedisConfig.java             # Redis 序列化配置
├── constant/
│   ├── ApiCodeConstants.java        # API 响应码
│   ├── JwtConstants.java            # JWT 相关常量
│   ├── RedisConstants.java          # Redis Key 前缀 & 过期时间
│   └── UserConstants.java           # 用户状态常量
├── exception/
│   ├── BusinessException.java       # 业务异常
│   └── GlobalExceptionHandler.java  # 全局异常处理器
└── utils/
    ├── JwtUtil.java                 # JWT 工具类
    ├── RedisUtil.java               # Redis 工具类
    └── Result.java                  # 统一响应结果
```

## 统一响应体 — Result\<T\>

**源文件**：`common/utils/Result.java`

所有 API 接口统一返回 `Result<T>` 格式：

```java
@Data
@Accessors(chain = true)
public class Result<T> implements Serializable {
    private int code;        // 响应码
    private String message;  // 响应消息
    private T data;          // 响应数据
    private long timestamp;  // 时间戳（毫秒）
}
```

### 静态工厂方法

| 方法 | code | 说明 |
|------|------|------|
| `Result.success()` | 200 | 无数据成功响应 |
| `Result.success(data)` | 200 | 带数据成功响应 |
| `Result.success(message, data)` | 200 | 自定义消息 + 数据 |
| `Result.error()` | 500 | 通用错误 |
| `Result.error(message)` | 500 | 自定义错误消息 |
| `Result.error(code, message)` | 自定义 | 自定义 code + 消息 |
| `Result.badRequest(message)` | 400 | 参数错误 |
| `Result.unauthorized(message)` | 401 | 未认证 |
| `Result.forbidden(message)` | 403 | 无权限 |
| `Result.notFound(message)` | 404 | 资源不存在 |

### 响应示例

```json
{
  "code": 200,
  "message": "登录成功",
  "data": {
    "token": "eyJhbGciOiJIUzUxMiJ9...",
    "userInfo": { "id": 1, "username": "admin", ... }
  },
  "timestamp": 1720000000000
}
```

## 全局异常处理器 — GlobalExceptionHandler

**源文件**：`common/exception/GlobalExceptionHandler.java`

使用 `@RestControllerAdvice` 统一捕获异常并返回 `Result<T>`：

| 异常类型 | HTTP 状态 | 处理逻辑 |
|----------|-----------|----------|
| `BusinessException` | 200 | 返回 `Result.error(code, message)` |
| `MethodArgumentNotValidException` | 400 | 提取字段校验错误信息，逗号拼接 |
| `BindException` | 400 | 提取绑定错误信息 |
| `ConstraintViolationException` | 400 | 提取约束校验信息 |
| `Exception`（兜底） | 500 | 返回 "系统繁忙，请稍后重试" |

## 业务异常 — BusinessException

**源文件**：`common/exception/BusinessException.java`

```java
public class BusinessException extends RuntimeException {
    private int code;

    public BusinessException(String message) { ... }
    public BusinessException(int code, String message) { ... }
}
```

用于业务逻辑中主动抛出异常，由 `GlobalExceptionHandler` 统一捕获并转为 `Result<T>` 响应。

**使用示例**：
```java
if (userMapper.existsByUsername(username)) {
    throw new BusinessException("用户名已存在");
}
```

## JWT 工具类 — JwtUtil

**源文件**：`common/utils/JwtUtil.java`

| 方法 | 说明 |
|------|------|
| `generateToken(userId, username)` | 生成 JWT Token（HS512 签名） |
| `getUserIdFromToken(token)` | 从 Token 提取 userId |
| `getUsernameFromToken(token)` | 从 Token 提取 username |
| `validateToken(token)` | 验证 Token 有效性 |
| `isTokenExpired(token)` | 检查 Token 是否过期 |
| `refreshToken(token)` | 刷新 Token（保留 claims，更新签发/过期时间） |

### Token 结构

```
Header: { "alg": "HS512" }
Payload: {
  "userId": "1",
  "username": "admin",
  "sub": "admin",
  "iat": 1720000000,
  "exp": 1720086400       // 默认 24 小时（86400000 ms）
}
Signature: HS512(payload, secret)
```

### 配置项

| 配置 | 默认值 | 说明 |
|------|--------|------|
| `jwt.secret` | `ink-sms-gateway-jwt-secret-key-...` | 签名密钥（≥32 字节） |
| `jwt.expiration` | `86400000` | 过期时间（毫秒），默认 24 小时 |

## Redis 工具类 — RedisUtil

**源文件**：`common/utils/RedisUtil.java`

### 通用操作

| 方法 | 说明 |
|------|------|
| `set(key, value)` | 设置值 |
| `set(key, value, timeout, unit)` | 设置值 + 过期时间 |
| `get(key)` | 获取值 |
| `delete(key)` | 删除 Key |
| `hasKey(key)` | Key 是否存在 |
| `expire(key, timeout, unit)` | 设置过期时间 |
| `getExpire(key)` | 获取剩余过期时间 |

### 用户 Token 操作

| 方法 | Redis Key | 过期时间 |
|------|-----------|----------|
| `setUserToken(userId, token)` | `user:token:{userId}` | 24 小时 |
| `getUserToken(userId)` | `user:token:{userId}` | - |
| `removeUserToken(userId)` | `user:token:{userId}` | - |

### 用户信息操作

| 方法 | Redis Key | 过期时间 |
|------|-----------|----------|
| `setUserInfo(userId, userInfo)` | `user:info:{userId}` | 24 小时 |
| `getUserInfo(userId)` | `user:info:{userId}` | - |
| `removeUserInfo(userId)` | `user:info:{userId}` | - |

### 短信验证码操作（预留）

| 方法 | Redis Key | 过期时间 |
|------|-----------|----------|
| `setSmsCode(phone, code)` | `sms:code:{phone}` | 5 分钟 |
| `getSmsCode(phone)` | `sms:code:{phone}` | - |
| `removeSmsCode(phone)` | `sms:code:{phone}` | - |

## 常量定义

### ApiCodeConstants — API 响应码

| 常量 | 值 | 说明 |
|------|-----|------|
| `SUCCESS` | 200 | 成功 |
| `UNAUTHORIZED` | 401 | 未认证 |
| `FORBIDDEN` | 403 | 无权限 |
| `NOT_FOUND` | 404 | 未找到 |
| `INTERNAL_ERROR` | 500 | 服务器内部错误 |

### JwtConstants — JWT 常量

| 常量 | 值 | 说明 |
|------|-----|------|
| `TOKEN_HEADER` | `Authorization` | Token 请求头名称 |
| `TOKEN_PREFIX` | `Bearer ` | Token 前缀 |
| `USER_ID_KEY` | `userId` | JWT payload 中 userId 的 key |
| `USERNAME_KEY` | `username` | JWT payload 中 username 的 key |
| `EXPIRATION_TIME` | `86400000L` | 默认过期时间（24h，毫秒） |

### RedisConstants — Redis 常量

| 常量 | 值 | 说明 |
|------|-----|------|
| `USER_TOKEN_PREFIX` | `user:token:` | 用户 Token Key 前缀 |
| `USER_INFO_PREFIX` | `user:info:` | 用户信息 Key 前缀 |
| `SMS_CODE_PREFIX` | `sms:code:` | 短信验证码 Key 前缀 |
| `TOKEN_EXPIRE_TIME` | `86400` | Token 过期时间（24h，秒） |
| `SMS_CODE_EXPIRE_TIME` | `300` | 验证码过期时间（5min，秒） |

### UserConstants — 用户常量

| 常量 | 值 | 说明 |
|------|-----|------|
| `DEFAULT_PASSWORD` | `123456` | 默认密码 |
| `STATUS_NORMAL` | `1` | 正常状态 |
| `STATUS_DISABLED` | `0` | 禁用状态 |
