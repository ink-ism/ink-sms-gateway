# 数据库设计

## 概述

项目使用 **MySQL 8.0** 作为持久化存储，数据库名 `ink_sms_gateway`，字符集 `utf8mb4`，排序规则 `utf8mb4_unicode_ci`。

初始化脚本位于：`user-service/src/main/resources/db/init.sql`

## 数据库创建

```sql
CREATE DATABASE IF NOT EXISTS ink_sms_gateway
  DEFAULT CHARACTER SET utf8mb4
  COLLATE utf8mb4_unicode_ci;
```

## 表结构

### users — 用户表

| 字段 | 类型 | 约束 | 默认值 | 说明 |
|------|------|------|--------|------|
| `id` | BIGINT | PK, AUTO_INCREMENT | - | 主键 |
| `username` | VARCHAR(20) | NOT NULL, UNIQUE | - | 用户名 |
| `password` | VARCHAR(100) | NOT NULL | - | BCrypt 加密密码 |
| `email` | VARCHAR(100) | NOT NULL, UNIQUE | - | 邮箱 |
| `phone` | VARCHAR(11) | NOT NULL, UNIQUE | - | 手机号 |
| `nickname` | VARCHAR(50) | - | NULL | 昵称 |
| `avatar` | VARCHAR(255) | - | NULL | 头像 URL |
| `status` | TINYINT | - | 1 | 状态：0=禁用，1=正常 |
| `create_time` | DATETIME | - | CURRENT_TIMESTAMP | 创建时间 |
| `update_time` | DATETIME | - | CURRENT_TIMESTAMP ON UPDATE | 更新时间 |
| `last_login_time` | DATETIME | - | NULL | 最后登录时间 |
| `last_login_ip` | VARCHAR(45) | - | NULL | 最后登录 IP（兼容 IPv6） |

**存储引擎**：InnoDB
**字符集**：utf8mb4
**表注释**：用户表

### 建表 DDL

```sql
CREATE TABLE IF NOT EXISTS users (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    username VARCHAR(20) NOT NULL UNIQUE COMMENT '用户名',
    password VARCHAR(100) NOT NULL COMMENT '密码',
    email VARCHAR(100) NOT NULL UNIQUE COMMENT '邮箱',
    phone VARCHAR(11) NOT NULL UNIQUE COMMENT '手机号',
    nickname VARCHAR(50) DEFAULT NULL COMMENT '昵称',
    avatar VARCHAR(255) DEFAULT NULL COMMENT '头像',
    status TINYINT DEFAULT 1 COMMENT '状态：0-禁用，1-正常',
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    last_login_time DATETIME DEFAULT NULL COMMENT '最后登录时间',
    last_login_ip VARCHAR(45) DEFAULT NULL COMMENT '最后登录IP',
    INDEX idx_username (username),
    INDEX idx_email (email),
    INDEX idx_phone (phone),
    INDEX idx_status (status),
    INDEX idx_create_time (create_time)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户表';
```

## 索引设计

| 索引名 | 字段 | 类型 | 用途 |
|--------|------|------|------|
| `PRIMARY` | `id` | 主键 | 主键查询 |
| `username` (UNIQUE) | `username` | 唯一索引 | 登录查询 + 唯一约束 |
| `email` (UNIQUE) | `email` | 唯一索引 | 邮箱查询 + 唯一约束 |
| `phone` (UNIQUE) | `phone` | 唯一索引 | 手机号查询 + 唯一约束 |
| `idx_username` | `username` | 普通索引 | 加速用户名查询（与 UNIQUE 冗余） |
| `idx_email` | `email` | 普通索引 | 加速邮箱查询 |
| `idx_phone` | `phone` | 普通索引 | 加速手机号查询 |
| `idx_status` | `status` | 普通索引 | 按状态筛选 |
| `idx_create_time` | `create_time` | 普通索引 | 按创建时间排序/范围查询 |

> 注意：`username`、`email`、`phone` 已声明 `UNIQUE` 约束，MySQL 会自动创建唯一索引。额外的 `INDEX idx_xxx` 在功能上与唯一索引重复，但不会报错，可视为冗余索引。

## MyBatis 映射关系

`UserMapper.xml` 中定义了 `BaseResultMap`，数据库字段（下划线）与 Java 实体（驼峰）的映射：

| 数据库字段 | Java 属性 | 类型 |
|-----------|-----------|------|
| `id` | `id` | Long |
| `username` | `username` | String |
| `password` | `password` | String |
| `email` | `email` | String |
| `phone` | `phone` | String |
| `nickname` | `nickname` | String |
| `avatar` | `avatar` | String |
| `status` | `status` | Integer |
| `create_time` | `createTime` | LocalDateTime |
| `update_time` | `updateTime` | LocalDateTime |
| `last_login_time` | `lastLoginTime` | LocalDateTime |
| `last_login_ip` | `lastLoginIp` | String |

MyBatis 配置已开启 `map-underscore-to-camel-case: true`，理论上可自动映射，但 XML 中仍显式定义了 `resultMap` 以确保精确控制。

## SQL 操作汇总

| 操作 | SQL 类型 | 说明 |
|------|----------|------|
| 按用户名查询 | SELECT | `WHERE username = ?` |
| 按邮箱查询 | SELECT | `WHERE email = ?` |
| 按手机号查询 | SELECT | `WHERE phone = ?` |
| 按 ID 查询 | SELECT | `WHERE id = ?` |
| 查询全部 | SELECT | `ORDER BY create_time DESC` |
| 分页查询 | SELECT | `ORDER BY create_time DESC LIMIT ?, ?` |
| 统计总数 | SELECT | `SELECT COUNT(*)` |
| 插入用户 | INSERT | 自增主键回填（`useGeneratedKeys=true`） |
| 更新用户 | UPDATE | 密码字段条件更新（非空时才更新） |
| 删除用户 | DELETE | `WHERE id = ?` |
| 更新状态 | UPDATE | `SET status = ?, update_time = NOW()` |
| 更新登录信息 | UPDATE | `SET last_login_time = ?, last_login_ip = ?` |
| 检查用户名存在 | SELECT | `COUNT(*) > 0 WHERE username = ?` |
| 检查邮箱存在 | SELECT | `COUNT(*) > 0 WHERE email = ?` |
| 检查手机号存在 | SELECT | `COUNT(*) > 0 WHERE phone = ?` |
