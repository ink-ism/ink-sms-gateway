# 前端架构详解

## 概述

前端是一个基于 **Vue 3 + TypeScript + Element Plus** 的 SPA 单页应用，使用 Vite 构建，运行在 `:3000`。

## 目录结构

```
front/src/
├── api/
│   └── user.ts                # 用户相关 API 封装
├── components/
│   └── AppLayout.vue          # 全局布局组件（Header + Sidebar + Main）
├── router/
│   └── index.ts               # 路由配置 & 导航守卫
├── stores/
│   └── user.ts                # Pinia 用户状态管理
├── types/
│   └── index.ts               # TypeScript 类型定义
├── utils/
│   └── axios.ts               # Axios 实例 & 拦截器
├── views/
│   ├── Home.vue               # 首页
│   ├── Login.vue              # 登录页
│   ├── Register.vue           # 注册页
│   ├── Dashboard.vue          # 仪表盘
│   ├── Profile.vue            # 个人中心
│   ├── Users.vue              # 用户管理
│   └── NotFound.vue           # 404 页面
├── App.vue                    # 根组件
└── main.ts                    # 入口文件
```

## Vite 配置

**源文件**：`front/vite.config.ts`

```typescript
export default defineConfig({
  plugins: [vue()],
  server: {
    port: 3000,
    proxy: {
      '/api': {
        target: 'http://localhost:8080',  // 代理到网关
        changeOrigin: true,
      },
    },
  },
  build: {
    outDir: 'dist',
    assetsDir: 'assets',
    sourcemap: false,
  },
})
```

开发环境下，所有 `/api` 开头的请求会被代理到网关 `localhost:8080`。

## 路由配置

**源文件**：`front/router/index.ts`

### 路由表

| 路径 | 组件 | 需要登录 | 说明 |
|------|------|----------|------|
| `/` | Home | 否 | 首页 |
| `/login` | Login | 否 | 登录页 |
| `/register` | Register | 否 | 注册页 |
| `/dashboard` | Dashboard | 是 | 仪表盘 |
| `/profile` | Profile | 是 | 个人中心 |
| `/users` | Users | 是 | 用户管理 |
| `/:pathMatch(.*)*` | NotFound | 否 | 404 兜底 |

### 导航守卫

```typescript
router.beforeEach((to, from, next) => {
  const token = localStorage.getItem('token')

  if (to.meta.requiresAuth && !token) {
    next('/login')          // 需登录页面 → 跳转登录
  } else if (to.path === '/login' && token) {
    next('/dashboard')      // 已登录访问登录页 → 跳转仪表盘
  } else {
    next()
  }
})
```

## Axios 封装

**源文件**：`front/utils/axios.ts`

### 实例配置

```typescript
const service = axios.create({
  baseURL: '/api',        // 统一前缀
  timeout: 10000,         // 10 秒超时
  headers: { 'Content-Type': 'application/json' }
})
```

### 请求拦截器

自动从 `localStorage` 读取 token 并注入 `Authorization: Bearer <token>` 请求头。

### 响应拦截器

- **code === 200**：直接返回 `ApiResponse` 数据
- **code !== 200**：`ElMessage.error` 提示错误消息，返回 `Promise.reject`
- **HTTP 错误码处理**：

| 状态码 | 行为 |
|--------|------|
| 401 | 清除 token/userInfo → 跳转 `/login` |
| 403 | 提示 "没有权限访问" |
| 404 | 提示 "请求的资源不存在" |
| 500 | 提示 "服务器内部错误" |
| 其他 | 提示响应中的 message |
| 网络错误 | 提示 "网络错误，请检查网络连接" |

## TypeScript 类型定义

**源文件**：`front/types/index.ts`

```typescript
// 用户信息
interface User {
  id: number
  username: string
  email: string
  phone: string
  nickname: string
  avatar: string
  status: number
  createTime: string
  updateTime: string
}

// 登录请求
interface LoginRequest { username: string; password: string }

// 注册请求
interface RegisterRequest { username: string; password: string; email: string; phone: string }

// 用户更新请求
interface UserUpdateRequest { username: string; email: string; phone: string; nickname: string; avatar: string }

// 密码修改请求
interface PasswordUpdateRequest { oldPassword: string; newPassword: string }

// API 统一响应
interface ApiResponse<T = unknown> { code: number; message: string; data: T; timestamp: number }

// 登录响应
interface LoginResponse { token: string; userInfo: User }
```

## Pinia 状态管理

**源文件**：`front/stores/user.ts`

使用 Composition API 风格定义 `useUserStore`：

### State

| 状态 | 类型 | 来源 | 说明 |
|------|------|------|------|
| `token` | `string` | localStorage | JWT Token |
| `userInfo` | `User \| null` | localStorage | 用户信息 |

### Computed

| 属性 | 说明 |
|------|------|
| `isLoggedIn` | `!!token.value` — 是否已登录 |
| `nickname` | 优先取 nickname，fallback 到 username |

### Actions

| 方法 | 说明 |
|------|------|
| `login(credentials)` | 调用 API → 存储 token + userInfo 到 state 和 localStorage |
| `logout()` | 调用 API（失败也清除本地） → 清空 state + localStorage |
| `fetchUserInfo()` | 调用 API 获取最新用户信息 → 更新 state + localStorage |
| `clearAuth()` | 仅清除本地状态，不调用 API |

## API 层封装

**源文件**：`front/api/user.ts`

所有 API 函数基于封装后的 Axios 实例，路径不含 `/api` 前缀（已在 `baseURL` 中配置）：

| 函数 | HTTP | 路径 | 说明 |
|------|------|------|------|
| `login(data)` | POST | `/user/login` | 登录 |
| `register(data)` | POST | `/user/register` | 注册 |
| `logout()` | POST | `/user/logout` | 登出 |
| `getUserInfo()` | GET | `/user/info` | 获取当前用户信息 |
| `updateUser(data)` | PUT | `/user/info` | 更新用户信息 |
| `updatePassword(data)` | PUT | `/user/password` | 修改密码 |
| `getUserList(page, size)` | GET | `/user/list` | 用户列表（分页） |
| `getUserCount()` | GET | `/user/count` | 用户总数 |
| `disableUser(userId)` | PUT | `/user/{userId}/disable` | 禁用用户 |
| `enableUser(userId)` | PUT | `/user/{userId}/enable` | 启用用户 |

## 布局组件

**源文件**：`front/components/AppLayout.vue`

采用 Element Plus 的 `el-container` 布局：

```
┌──────────────────────────────────────┐
│  Header: INK短信网关    [用户▼]      │
├──────────┬───────────────────────────┤
│ Sidebar  │                           │
│          │     Main Content          │
│ · 首页   │     （<slot />）           │
│ · 用户管理│                           │
│ · 个人中心│                           │
└──────────┴───────────────────────────┘
```

- Header 右侧显示用户昵称下拉菜单（个人中心 / 退出登录）
- Sidebar 使用 `el-menu` + `router` 模式，根据当前路由高亮菜单项
- 退出登录调用 `userStore.logout()` → 跳转 `/login`

## 构建脚本

```bash
npm run dev       # 启动开发服务器（:3000，热更新）
npm run build     # 生产构建（vue-tsc 类型检查 → vite build）
npm run preview   # 预览生产构建结果
npm run lint      # ESLint 检查（Vue + TS 规则）
npm run format    # Prettier 格式化 src/ 目录
```
