# 用户服务详解

## 概述

用户服务（`user-service`）基于 **Spring Boot Web + MyBatis**，运行在 `:8081`，负责用户全生命周期管理：注册、登录、登出、信息查询/更新、密码修改、用户启禁用。

## 目录结构

```
user-service/src/main/
```

## 请求 DTO 校验规则

### UserRegisterRequest（注册）

| 字段 | 校验规则 |
|------|----------|
| `username` | `@NotBlank`，`@Size(min=3, max=20)` |
| `password` | `@NotBlank`，`@Size(min=6, max=20)` |
| `email` | `@NotBlank`，`@Email` |
| `phone` | `@NotBlank`，`@Size(min=11, max=11)` |

### UserLoginRequest（登录）

| 字段 | 校验规则 |
|------|----------|
| `username` | `@NotBlank` |
| `password` | `@NotBlank` |

### PasswordUpdateRequest（修改密码）

| 字段 | 校验规则 |
|------|----------|
| `oldPassword` | `@NotBlank` |
| `newPassword` | `@NotBlank`，`@Size(min=6, max=20)` |

### UserUpdateRequest（更新信息）

无校验注解，所有字段可选更新：`username`、`email`、`phone`、`nickname`、`avatar`。

## 用户实体

**源文件**：`user/entity/User.java`

```java
@Data
@NoArgsConstructor
@AllArgsConstructor
@Accessors(chain = true)
public class User {
    private Long id;
    private String username;
    private String password;
    private String email;
    private String phone;
    private String nickname;
    private String avatar;
    private Integer status;           // 0=禁用, 1=正常
    private LocalDateTime createTime;
    private LocalDateTime updateTime;
    private LocalDateTime lastLoginTime;
    private String lastLoginIp;
}
```

**工厂方法**：`User.create(username, password, email, phone)` — 自动设置 nickname 为 username，status 为 `STATUS_NORMAL(1)`。

**密码脱敏**：`maskPassword()` — 将 password 置 null，用于返回给前端前清除密码字段。

## 核心业务流程

### 注册流程

```
UserRegisterRequest
  │
  ├─ 用户名已存在？ → BusinessException("用户名已存在")
  ├─ 邮箱已注册？ → BusinessException("邮箱已被注册")
  ├─ 手机号已注册？ → BusinessException("手机号已被注册")
  │
  ├─ BCrypt 加密密码
  ├─ 设置 createTime / updateTime
  ├─ UserMapper.insert()
  │
  └─ 返回 "注册成功"
```

### 登录流程

```
UserLoginRequest + 客户端 IP
  │
  ├─ 查询用户 → 不存在 → "用户名或密码错误"
  ├─ 检查 status → 禁用 → "账号已被禁用"
  ├─ BCrypt 验证密码 → 失败 → "用户名或密码错误"
  │
  ├─ 生成 JWT Token（userId + username）
  ├─ 更新 last_login_time / last_login_ip
  ├─ Redis 缓存：user:token:{userId} = token（24h）
  ├─ Redis 缓存：user:info:{userId} = userInfo（24h）
  │
  └─ 返回 { token, userInfo }
```

### 登出流程

```
X-User-Id（从网关转发）
  │
  ├─ Redis 删除：user:token:{userId}
  ├─ Redis 删除：user:info:{userId}
  │
  └─ 返回 "登出成功"
```

### 密码修改流程

```
PasswordUpdateRequest + X-User-Id
  │
  ├─ 查询用户 → 不存在 → "用户不存在"
  ├─ BCrypt 验证旧密码 → 失败 → "原密码错误"
  ├─ BCrypt 加密新密码
  ├─ UserMapper.update()
  ├─ Redis 删除：user:token:{userId}（强制重新登录）
  │
  └─ 返回 "密码修改成功"
```

### 用户启禁用

- **禁用**：检查用户存在 → `updateStatus(userId, 0)` → Redis 删除 token（踢下线）
- **启用**：检查用户存在 → `updateStatus(userId, 1)`

## Security 配置

**源文件**：`user/config/SecurityConfig.java`

```java
@Configuration
@EnableWebSecurity
public class SecurityConfig {
    @Bean
    public BCryptPasswordEncoder passwordEncoder() { ... }

    @Bean
    public SecurityFilterChain securityFilterChain(HttpSecurity http) {
        http.csrf(csrf -> csrf.disable())
            .sessionManagement(session -> session.sessionCreationPolicy(STATELESS))
            .authorizeHttpRequests(auth -> auth.anyRequest().permitAll());
        return http.build();
    }
}
```

**设计说明**：
- 认证由网关 JWT 过滤器统一处理，用户服务本身不做认证拦截
- 仅使用 Spring Security 的 `BCryptPasswordEncoder` 进行密码加密/验证
- CSRF 禁用（无状态 API）
- Session 策略设为 `STATELESS`

## MyBatis Mapper

**接口**：`user/mapper/UserMapper.java`
**XML 映射**：`user/resources/mapper/UserMapper.xml`

### 方法清单

| 方法 | SQL | 说明 |
|------|-----|------|
| `findByUsername` | `SELECT ... WHERE username = ?` | 按用户名查询 |
| `findByEmail` | `SELECT ... WHERE email = ?` | 按邮箱查询 |
| `findByPhone` | `SELECT ... WHERE phone = ?` | 按手机号查询 |
| `findById` | `SELECT ... WHERE id = ?` | 按 ID 查询 |
| `findAll` | `SELECT ... ORDER BY create_time DESC` | 查询全部 |
| `findByPage` | `SELECT ... LIMIT ?, ?` | 分页查询 |
| `count` | `SELECT COUNT(*)` | 用户总数 |
| `insert` | `INSERT INTO users ...` | 插入用户（自增主键回填） |
| `update` | `UPDATE users SET ...` | 更新用户（密码可选更新） |
| `deleteById` | `DELETE FROM users WHERE id = ?` | 删除用户 |
| `updateStatus` | `UPDATE users SET status = ?` | 更新状态 |
| `updateLastLoginTime` | `UPDATE users SET last_login_time = ?, last_login_ip = ?` | 更新登录信息 |
| `existsByUsername` | `SELECT COUNT(*) > 0 WHERE username = ?` | 用户名是否存在 |
| `existsByEmail` | `SELECT COUNT(*) > 0 WHERE email = ?` | 邮箱是否存在 |
| `existsByPhone` | `SELECT COUNT(*) > 0 WHERE phone = ?` | 手机号是否存在 |

### MyBatis 配置

```yaml
mybatis:
  mapper-locations: classpath:mapper/*.xml
  type-aliases-package: com.ink.user.entity
  configuration:
    map-underscore-to-camel-case: true   # 下划线 → 驼峰自动映射
    cache-enabled: true
    lazy-loading-enabled: true
    use-generated-keys: true
    default-executor-type: REUSE
    default-statement-timeout: 25000
```

## Redis 缓存策略

| Key 模式 | 值 | 过期时间 | 用途 |
|----------|-----|----------|------|
| `user:token:{userId}` | JWT Token 字符串 | 24 小时 | 存储用户 Token |
| `user:info:{userId}` | 用户信息 Map | 24 小时 | 缓存用户基本信息 |
| `sms:code:{phone}` | 验证码字符串 | 5 分钟 | 短信验证码（预留） |

缓存操作集中在 `RedisUtil`（common 模块），用户服务在登录/登出/修改密码/禁用用户时触发缓存更新。
