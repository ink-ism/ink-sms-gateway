# 网关服务详解

## 概述

网关服务（`gateway-service`）基于 **Spring Cloud Gateway**（WebFlux 响应式模型），运行在 `:8001`，是所有前端请求进入后端微服务的唯一入口。

**核心职责**：路由分发、JWT 认证拦截、CORS 跨域处理、IP 限流。

## 目录结构

```
gateway/src/main/java/com/ink/gateway/
├── GatewayApplication.java          # 启动类
├── config/
│   └── GatewayConfig.java           # 网关配置（CORS + 限流）
├── controller/
│   └── GatewayController.java       # 网关状态 & 健康检查接口
└── filter/
    └── JwtAuthenticationFilter.java # JWT 全局过滤器
```

## JWT 全局过滤器

`JwtAuthenticationFilter` 实现了 `GlobalFilter` + `Ordered`，对所有经过网关的请求进行认证。

**源文件**：`gateway/filter/JwtAuthenticationFilter.java`

### 认证流程

```
请求进入
  │
  ├─ 路径匹配白名单？ ──是──▶ 直接放行 → chain.filter()
  │
  └─ 否
     │
     ├─ 请求头有 Authorization: Bearer <token>？ ──否──▶ 返回 401 "未提供有效的认证令牌"
     │
     └─ 是 → 解析 JWT
              │
              ├─ 验证成功 → 提取 userId / username → 注入 X-User-Id / X-Username 请求头 → 转发下游
              │
              └─ 验证失败 → 返回 401 "无效的认证令牌"
```

### 白名单路径

以下路径无需认证，直接放行：

| 路径前缀 | 说明 |
|----------|------|
| `/api/user/login` | 用户登录 |
| `/api/user/register` | 用户注册 |
| `/swagger-ui/` | Swagger UI |
| `/v3/api-docs/` | OpenAPI 文档 |
| `/actuator/` | 健康检查端点 |
| `/favicon.ico` | 图标 |

### 请求头传递

认证通过后，过滤器将 JWT 中的用户信息注入到下游请求头：

| 请求头 | 来源 | 用途 |
|--------|------|------|
| `X-User-Id` | JWT payload `userId` | 下游服务识别当前用户 |
| `X-Username` | JWT payload `username` | 下游服务获取用户名 |

下游 Controller 通过 `@RequestHeader("X-User-Id")` 接收。

### 错误响应格式

认证失败时返回 JSON：

```json
{
  "code": 401,
  "message": "未提供有效的认证令牌",
  "data": null,
  "timestamp": 1720000000000
}
```

### 关键配置

```java
@Value("${jwt.secret:ink-sms-gateway-jwt-secret-key-must-be-at-least-256-bits-long-for-hs512}")
private String jwtSecret;

@Override
public int getOrder() {
    return -100;  // 高优先级执行
}
```

- 签名算法：HS512
- 密钥要求：≥ 256 bit（32 字节）
- 过滤器优先级：`-100`（数值越小越先执行）

## 网关配置类

**源文件**：`gateway/config/GatewayConfig.java`

### CORS 跨域过滤器

```java
@Bean
public WebFilter corsFilter() {
    // Access-Control-Allow-Origin: *
    // Access-Control-Allow-Methods: GET, POST, PUT, DELETE, OPTIONS
    // Access-Control-Allow-Headers: *
    // Access-Control-Max-Age: 3600
    // OPTIONS 请求直接返回 200
}
```

### IP 限流 Key 解析器

```java
@Bean
public KeyResolver ipKeyResolver() {
    return exchange -> Mono.just(
        exchange.getRequest().getRemoteAddress().getAddress().getHostAddress()
    );
}
```

按客户端 IP 进行限流，配合 Gateway 的 `RequestRateLimiter` 过滤器使用。

## 路由配置

**源文件**：`gateway/resources/application.yml`

```yaml
spring:
  cloud:
    gateway:
      discovery:
        locator:
          enabled: true              # 开启服务发现路由
          lower-case-service-id: true
      routes:
        - id: user-service
          uri: lb://user-service     # 负载均衡到用户服务
          predicates:
            - Path=/api/user/**      # 匹配 /api/user/ 下所有路径
        - id: api-service
          uri: lb://api-service      # 负载均衡到 API 服务
          predicates:
            - Path=/api/sms/**       # 匹配 /api/sms/ 下所有路径
```

- 使用 `lb://` 前缀表示通过 Nacos 服务发现进行负载均衡
- 服务发现路由已开启，理论上注册到 Nacos 的服务会自动生成路由规则

## Nacos 注册

```yaml
spring:
  cloud:
    nacos:
      discovery:
        server-addr: localhost:8848
        namespace: public
        group: DEFAULT_GROUP
```

## 注意事项

- 网关基于 **WebFlux**，不可引入 `spring-boot-starter-web` 或 Servlet 相关依赖（如 `knife4j-openapi3-jakarta-spring-boot-starter`），否则会导致启动冲突
- 网关的 Knife4j 配置虽然存在于 `application.yml` 中，但实际 WebFlux 环境下不生效
- JWT 密钥长度必须 ≥ 256 bit，否则 HS512 签名会抛出异常
